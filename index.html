Download Pathloose iPhone Game (.ipa) ↓

Important: iOS cannot install this unsigned IPA by simply tapping the downloaded file. It must first be signed with an Apple ID for the iPhone using AltStore Classic and AltServer on a Mac or Windows PC.

  1. On your friend's iPhone, download the Pathloose IPA above and save it in Files.
  2. On her Mac or Windows computer, install AltServer and use it to install AltStore Classic on her iPhone.
  3. In AltStore Classic on the iPhone, open My Apps → +, choose the downloaded Pathloose IPA, and sign in to her own Apple Account when prompted.
  4. Once installed, open Pathloose from the iPhone home screen and make the physical-device gameplay recording Apple requested.

How to prepare the iPhone

Use a real iPhone that runs the latest iOS for the recording Apple requested.

01 · DeviceCheck the iOS version

On the iPhone, open Settings → General → About. Use Settings → General → Software Update to install the latest available iOS.

02 · RegisterGet the UDID privately

Connect the iPhone to a trusted computer. On a Mac, select it in Finder and click the device details to reveal the UDID. On Windows, compatible Apple device tools or iTunes can display the identifier.

03 · RecordCapture real gameplay

Start iPhone Screen Recording, launch Pathloose, open Play Level, solve part of a puzzle, and demonstrate Daily Race, Weekly Challenge, Collections, and Leaderboard.

Important: A website cannot install an ordinary App Store-signed IPA on a random iPhone. For direct installation, Apple requires an appropriately signed Ad Hoc build and that iPhone's registered UDID. Do not post the UDID publicly.
